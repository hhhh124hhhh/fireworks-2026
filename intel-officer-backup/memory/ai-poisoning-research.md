## 🎯 什么是 AI 投毒？

### 定义
**AI 投毒**（AI Poisoning）是指通过人为操控训练数据或搜索结果，影响 AI 大模型的输出，使其推荐特定产品、服务或观点的黑产行为。

### 核心手法

#### 1. GEO 投毒（生成引擎优化）
```
原理：针对 AI 搜索/推荐系统进行优化
手法：
- 批量生产"测评文章"
- 操控问答平台内容
- 刷高特定产品曝光度
成本：几万 - 几十万元
效果：AI 推荐排名提升 3-5 倍
```

#### 2. 数据投毒
```
原理：污染 AI 训练数据集
手法：
- 向公开数据集注入虚假信息
- 批量注册账号发布倾向性内容
- 利用爬虫抓取机制污染数据
成本：几十万 - 几百万元
效果：长期影响 AI 输出
```

#### 3. 搜索结果操控
```
原理：操控 AI 搜索的引用源
手法：
- SEO 优化 + 内容农场
- 刷高权威度评分
- 建立"信息茧房"
成本：几万 - 几十万元/月
效果：搜索结果前 3 位可控
```

```

⚠️ 警惕无官方背书

```
✅ 本地部署（如 OpenClaw）

```

```
