## 📊 经验内容统计

### 小红书 (xiaohongshu.md)

**平台特征**:
- 强反爬，必须登录态
- 内容动态加载，需滚动触发懒加载
- 搜索需要处理验证码
- API 大量使用 GraphQL

**有效模式**:
- 搜索 URL 模式
- 首页推荐 URL
- 用户主页 URL
- 笔记详情 URL
- eval 提取示例代码

**已知陷阱**:
1. 2026-03-20: 详情页 403（需从搜索结果页点击进入）
2. 2026-03-21: 滑块验证码（降低频率）
3. 2026-03-22: 图片懒加载（先滚动再提取）
4. 2026-03-23: 评论分页（滚动触发加载）

---

### 知乎 (zhihu.md)

**平台特征**:
- 部分内容需要登录（尤其是评论）
- 回答可折叠/展开
- 中等反爬，高频访问触发验证码
- 富文本编辑器内容

**有效模式**:
- 问题页/回答详情 URL
- 热搜榜 URL
- eval 提取回答列表/问题信息

**已知陷阱**:
1. 2026-03-15: 折叠回答（点击展开）
2. 2026-03-18: 评论需要登录
3. 2026-03-20: 验证码（降低频率）
4. 2026-03-22: 图片延迟加载

---

### 即刻 (jike.md)

**平台特征**:
- 必须登录才能查看内容
- 圈子 + 动态，类似微博
- 滚动加载，无限瀑布流

**有效模式**:
- 首页/圈子/用户主页 URL
- eval 提取动态列表

**已知陷阱**:
1. 2026-03-10: 登录验证
2. 2026-03-15: 图片懒加载
3. 2026-03-20: 评论嵌套（递归提取）

---

### 微博 (weibo.md)

**平台特征**:

**有效模式**:

**已知陷阱**:
1. 2026-03-12: 验证码

3. 2026-03-18: 内容折叠
4. 2026-03-20: 图片反爬（截图或 Referer）

## 🎯 使用流程

### 标准工作流程

```
1. 用户请求操作某网站
   ↓
2. 读取 site-patterns/{domain}.md
   ↓
3. 了解平台特征和已知陷阱
   ↓
4. 使用有效模式执行操作
   ↓
5. 成功 → 更新经验文件（如有新发现）
   失败 → 回退通用模式，更新经验文件
```

### 示例：操作小红书

```bash
# 1. 读取经验
read skills/opencli/site-patterns/xiaohongshu.md

# 2. 了解关键信息
# - 直接访问详情页会 403
# - 需要滚动触发懒加载
# - 高频搜索会触发验证码

# 3. 使用 opencli 命令
opencli xiaohongshu search --keyword "AI 工具" -f json

# 4. 如遇问题，用浏览器兜底
bb-browser open "https://www.xiaohongshu.com/search_result?keyword=AI 工具"
bb-browser scroll down
bb-browser eval "..."

# 5. 发现新模式，更新经验文件
```

## 📝 维护指南

### 何时更新经验文件

**操作成功后**:
- 发现新 URL 模式 → 添加到"有效模式"
- 发现新选择器 → 添加到"有效模式"
- 验证旧经验仍然有效 → 更新 `updated` 日期

**操作失败后**:
- 遇到新错误 → 添加到"已知陷阱"
- 旧经验失效 → 在陷阱中标注"已失效"
- 找到新解决方案 → 更新陷阱的"解决"部分

### 经验文件格式

```markdown
---
domain: example.com
aliases: [示例]
updated: YYYY-MM-DD
tested_by: bot3
---

## 平台特征
- 事实 1
- 事实 2

## 有效模式
### URL 模式
```
https://example.com/path
```

### eval 提取
```javascript
// 代码
```

## 已知陷阱
### YYYY-MM-DD: 问题标题
- **现象**: 描述
- **原因**: 分析
- **解决**: 方案
```
