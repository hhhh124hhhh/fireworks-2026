## 🔧 已知问题

### 1. arXiv 不支持
- **影响**: 无法抓取 AI 论文
- **临时方案**: 使用 arXiv API 直接调用
- **长期方案**: 等待 opencli 更新

### 2. V2EX 数量限制
- **问题**: opencli 仅返回 10 条（非 30 条）
- **影响**: 数据量减少 20 条
- **可接受**: V2EX 热度集中，Top10 足够

### 3. 小红书搜索关键词
- **问题**: 固定搜索"AI"，可能不够全面
- **优化**: 支持自定义关键词列表

## ✅ 测试结论

### 优势
1. ✅ **速度快** - 比传统脚本快 2-4.6 倍
2. ✅ **数据质量高** - 字段完整，格式标准
3. ✅ **维护成本低** - npm 包自动更新
4. ✅ **跨平台** - Python 脚本，Windows/Linux/macOS 通用

### 不足
1. ❌ arXiv 不支持（等待 opencli 更新）
2. ⚠️ V2EX 数量限制（10 条而非 30 条）
