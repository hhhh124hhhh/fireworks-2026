## 📁 技能创建工作流

### 1. 使用 skill-creator 创建基础结构

```bash
# 进入 skill-creator 目录
cd /root/clawd/skills/skill-creator

# 阅读指导
read SKILL.md

# 创建新技能（交互式）
# 遵循指导创建 SKILL.md
```

### 2. Skill 结构模板

```markdown
---
name: skill-name
description: 简洁描述技能用途和触发场景
homepage: https://clawdhub.com/skills/skill-name
metadata: {
  "clawdbot": {
    "emoji": "🎯",
    "pricing": {
      "type": "subscription|onetime",
      "price": 9.99,
      "currency": "USD"
    }
  }
}
---
```

### 3. 打包和发布

```bash
# 进入技能目录
cd /root/clawd/skills/skill-name

# 打包为 .skill 文件
cd /root/clawd && bash pack-skills.sh skill-name

# 登录 ClawdHub（如未登录）
clawdhub login

# 发布
clawdhub publish ./skills/skill-name \
  --slug skill-name \
  --name "Display Name" \
  --version 1.0.20260130 \
  --changelog "Initial release based on popular X prompt"
```
