## 完整工作流示例

### 示例 9: 从概念到最终提示词

#### 步骤 1: 初始概念
用户想要生成一个"雨中城市街道"的视频。

#### 步骤 2: 生成基础提示词
```
雨中城市街道，人们在行走，灯光反射
```

#### 步骤 3: 优化为 INTERMEDIATE 级别
```
雨中城市街道，人们在雨中匆忙行走，路灯的光线在湿润的路面上反射，雨滴在空中飘落。固定镜头拍摄，展现夜晚城市的雨景。
```

#### 步骤 4: 优化为 ADVANCED 级别
```
夜晚的城市街道，大雨倾盆，人们在雨中匆匆行走，打伞的身影在路灯下穿梭。路灯光线在湿润的路面上形成反射，雨滴在空中飘落，溅起水花。镜头从高处俯拍，缓缓下移，捕捉街道的纵深感和繁忙的氛围。冷色调的照明营造雨夜的清冷感。写实风格，高清画质，雨滴细节清晰，光影反射准确，氛围浓厚。
```

#### 步骤 5: 优化为 EXPERT 级别（最终版本）
```
一个繁华的城市十字路口，大雨倾盆而下，形成密集的雨幕。行人们撑着五颜六色的雨伞，在雨中匆匆穿行，身影在路灯和车灯的照射下形成清晰的剪影。路面完全湿润，雨水在表面形成流动的水膜，反射着路灯、车灯和霓虹灯的光芒，创造出绚烂的夜景效果。主光源来自高处的路灯，色温 3000K，强度 50%，形成温暖的橘黄色光晕。车灯从不同方向照射，色温 5500K，强度 60%，在湿润的路面上形成动态的反射轨迹。环境光来自两侧的建筑物窗户，色温 4000K，强度 30%，提供整体的环境照明。镜头采用 24mm 广角镜头，从上方 60 度角俯拍，缓慢螺旋下降，从全景逐渐过渡到中景，展现十字路口的全貌和行人的动态。运镜速度恒定，下移速度 0.5m/s，总运镜时间 12 秒。写实景观，8K 分辨率，60fps，Rec.709 色彩空间，雨滴物理模拟必须精确，光线反射必须符合光学原理，整体氛围既繁忙又富有诗意。
```

**元素分解**:
- 主体: 行人、雨幕、城市十字路口
- 动作: 匆匆穿行，伞影移动
- 场景: 繁华的城市十字路口
- 光影: 主光（路灯，3000K，50%）、车灯（5500K，60%）、环境光（4000K，30%）
- 镜头: 24mm 广角，螺旋下降（12秒）
- 风格: 写实景观
- 画质: 8K，60fps，Rec.709
- 约束: 雨滴物理模拟精确，光线反射符合光学原理

## 常见错误示例

### 错误示例 1: 过于模糊

**错误提示词**:
```
一个人在做某事
```

**问题**:
- 主体描述过于模糊（"一个人"）
- 动作描述不具体（"做某事"）
- 缺少场景描述
- 缺少任何技术参数

**正确写法**:
```
一位年轻女性在咖啡馆里阅读一本书，阳光透过窗户洒在她身上，固定镜头拍摄。
```

---

### 错误示例 2: 冲突的描述

**错误提示词**:
```
在夜晚的黑暗环境中，明亮阳光照射着场景
```

**问题**:
- 光影描述自相矛盾（夜晚 vs 明亮阳光）
- 物理上不可能实现

**正确写法**:
```
在夜晚的城市街道上，路灯和车灯提供照明，营造出明亮的夜景。
```

---

### 错误示例 3: 过度复杂的约束

**错误提示词**:
```
一个人在走，必须同时做到：速度严格控制在 1.2m/s，每步长度 0.6m，每分钟走 100 步，姿势角度精确到 1 度，呼吸频率 20 次/分，心跳 70 次/分，眼神必须保持 45 度角，手臂摆动幅度 15 度
```

**问题**:
- 约束过于详细且不必要
- 超出视频生成的合理范围
- 可能导致生成失败或效果不佳

**正确写法**:
```
一位中年人以自然悠闲的步伐在公园小径上散步，姿态轻松，步伐平稳。
```

---

### 错误示例 4: 缺少关键元素

**错误提示词**:
```
美丽的场景，有光线，有镜头
```

**问题**:
- 没有明确的主体
- 没有明确的动作
- 光线和镜头描述过于笼统
- 无法生成具体内容

**正确写法**:
```
一片盛开的向日葵花田，在阳光的照耀下金光闪闪，微风轻拂，向日葵轻轻摇曳。镜头从远处缓慢推进，聚焦到一朵向日葵的特写。
```

## 提示词写作最佳实践

### 1. 从简单开始
- 初学者: 使用 BEGINNER 级别
- 逐步增加复杂度
- 先掌握基础元素

### 2. 注重逻辑
- 确保描述在物理上合理
- 避免自相矛盾
- 保持时间线连贯

### 3. 使用具体词汇
- 避免过于抽象的描述
- 使用具体的名词和动词
- 增加形容词和副词

### 4. 参考模板
- 使用预设模板作为起点
- 根据需求修改模板
- 学习模板的结构

### 5. 迭代优化
- 初次生成后检查结果
- 根据结果调整提示词
- 多次迭代直到满意

### 6. 使用工具
- 使用优化器工具辅助
- 生成变体进行对比
- 利用评分系统指导改进

## 示例使用方法

### 在命令行中使用

```bash
# 生成提示词
python scripts/prompt_generator.py

# 优化提示词
python scripts/prompt_optimizer.py

# 查看示例
python scripts/examples.py
```

```python
from scripts.prompt_generator import generate_prompt

result = generate_prompt(
    scene="一位女士在花园里散步",
    style="梦幻",
    difficulty="INTERMEDIATE",
    video_type="photo-realistic"
)

print(result['prompt'])
```
