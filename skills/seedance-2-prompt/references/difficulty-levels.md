# 难度级别说明

Seedance 2.0 提示词系统提供 4 个难度级别，从初学者到专家，逐步提升复杂度和细节要求。

## 难度级别概览

| 级别 | 提示词长度 | 元素完整度 | 适用人群 | 推荐时长 |
|------|-----------|-----------|---------|---------|
| BEGINNER | 短小 (20-50 字) | 基础元素 | 初学者 | 4-10s |
| INTERMEDIATE | 中等 (50-100 字) | 增加光影镜头 | 有经验者 | 6-15s |
| ADVANCED | 较长 (100-200 字) | 完整公式 | 高级用户 | 8-20s |
| EXPERT | 极长 (200+ 字) | 极致细节 | 专家用户 | 10-30s |

## BEGINNER - 初学者

### 特点
- 简单直接的描述
- 基础元素组成
- 自然流畅即可
- 无需复杂术语

### 万能公式
```
主体 + 动作 + 场景
```

### 推荐元素
- ✅ 主体：简单明确的对象
- ✅ 动作：基础自然行为
- ✅ 场景：常见环境
- ⚠️ 光影：可选，自然光即可
- ⚠️ 镜头：可选，固定镜头
- ❌ 风格：无需指定
- ❌ 画质：无需指定
- ❌ 约束：无需指定

### 示例提示词

**示例 1**:
```
一位女士晾晒衣物
```
- 主体：一位女士
- 动作：晾晒衣物
- 场景：默认室内

**示例 2**:
```
咖啡在杯中缓慢冲泡
```
- 主体：咖啡
- 动作：缓慢冲泡
- 场景：杯子中

**示例 3**:
```
孩子打开礼物露出笑容
```
- 主体：孩子
- 动作：打开礼物露出笑容
- 场景：默认生日派对

### 提示词生成技巧
1. 使用简单词汇
2. 避免复杂句式
3. 专注于核心动作
4. 保持直观易懂

## EXPERT - 专家

### 特点
- 极致的细节程度
- 专业级的术语
- 复杂的约束条件
- 完美的技术参数

### 万能公式
```
极致详细的主体描述 + 完整的动作序列 + 多层次场景环境 + 专业级光影设置 + 电影级运镜方案 + 明确的风格定义 + 极致画质标准 + 严格的约束条件
```

### 推荐元素
- ✅ 主体：极致细节，包含材质、纹理、颜色等
- ✅ 动作：完整序列，包含起始、过程、结果
- ✅ 场景：多层次，包含前景、中景、背景
- ✅ 光影：多光源，包含主光、补光、轮廓光
- ✅ 镜头：电影级运镜，包含运镜轨迹、速度、角度
- ✅ 风格：专业级风格定义
- ✅ 画质：极致画质，包含分辨率、帧率、色彩空间
- ✅ 约束：严格的约束条件，可能包含技术参数

### 示例提示词

**示例 1**:

## 难度级别进阶指南

### 从 BEGINNER 到 INTERMEDIATE
1. 学习基本的摄影术语
2. 了解光线的基本类型
3. 掌握简单的运镜概念
4. 增加描述的详细程度

### 从 INTERMEDIATE 到 ADVANCED
1. 学习专业的影视术语
2. 了解复杂的光影设置
3. 掌握专业的运镜技术
4. 学习材质和纹理描述
5. 设定合理的约束条件

### 从 ADVANCED 到 EXPERT
1. 深入学习摄影和摄像技术
2. 掌握专业的色彩理论
3. 了解高级的物理和光学原理
4. 学习影视后期技术
5. 掌握专业级的画质标准

## 常见问题

### Q: 如何选择合适的难度级别？
A: 根据你的经验和目标选择。初学者可以从 BEGINNER 开始，逐步提升到 INTERMEDIATE。有经验者可以直接从 INTERMEDIATE 或 ADVANCED 开始。

### Q: 高难度级别一定能产生更好的结果吗？
A: 不一定。高难度级别提供更多的控制力，但也需要更多的专业知识。根据你的具体需求选择最合适的级别。

### Q: 可以混合不同难度的元素吗？
A: 可以。你可以在主要部分使用 ADVANCED 级别，在某些细节部分使用 EXPERT 级别。但建议保持整体难度的一致性。

### Q: 如何提高我的提示词写作水平？
A:
1. 多练习，从简单开始逐步提升
2. 学习摄影和摄像的基础知识
3. 研究优秀的提示词示例
4. 使用优化器工具辅助改进
5. 根据生成结果不断调整
