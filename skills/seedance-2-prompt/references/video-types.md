# 视频类型说明

Seedance 2.0 支持多种视频生成类型，每种类型都有其独特的特点和应用场景。

## 类型列表

### 1. 超逼真视频生成 (photo-realistic)

**特点**:
- 逼真的物理效果和光影表现
- 细腻的材质纹理和细节
- 电影级的视觉质量
- 强调真实感和自然流畅

**适用场景**:
- 真实生活场景
- 产品展示
- 建筑可视化
- 自然风景

**提示词重点**:
- 强调物理真实性
- 详细描述材质和纹理
- 注重光影效果
- 明确画质要求

**示例提示词结构**:
```
主体 + 真实动作 + 写实场景 + 自然光影 + 电影镜头 + 写实风格 + 超高清 + 物理约束
```

---

### 2. 角色与场景一致性 (character-consistency)

**特点**:
- 保持角色外观一致性
- 跨场景身份识别
- 统一服装和发型
- 稳定的身体比例

**适用场景**:
- 角色动画短片
- 品牌角色视频
- 多场景叙事
- 角色展示

**提示词重点**:
- 明确角色特征
- 强调一致性要求
- 描述服装和发型
- 保持动作连贯性

**示例提示词结构**:
```
一致的角色描述 + 连续动作 + 多场景切换 + 统一光线 + 稳定镜头 + 动画风格 + 高清 + 一致性约束
```

## 选择合适的视频类型

### 根据目标选择

| 目标 | 推荐类型 |
|------|---------|
| 真实感 | photo-realistic |
| 角色展示 | character-consistency |
| 空间展示 | camera-movement, one-shot |
| 创意表达 | creative-effects |
| 故事讲述 | storytelling |
| 音乐视频 | audio-sync |
| 情感表达 | emotion-performance |

### 根据难度选择

| 难度 | 推荐类型 |
|------|---------|
| 初学者 | photo-realistic (BEGINNER), emotion-performance (BEGINNER) |
| 中级 | character-consistency, camera-movement (INTERMEDIATE) |
| 高级 | creative-effects, storytelling |
| 专家 | photo-realistic (EXPERT), one-shot (ADVANCED) |

---

## 组合使用提示

不同类型可以相互结合，但需要注意：
1. **避免冲突**: 某些类型可能有冲突（如 photo-realistic 和 creative-effects）
2. **主次分明**: 确定主要类型，次要类型作为辅助
3. **难度匹配**: 确保组合的难度级别匹配
4. **测试验证**: 生成后检查是否符合预期效果
