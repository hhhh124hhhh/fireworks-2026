### 4. 环境检测优化

**修改位置**：`_detect_environment()` 方法

**修改内容**：
- 新增打戏场景检测逻辑
- 根据环境类型返回对应的打戏环境模板

```python
# 先检测是否是打戏场景
combat_keywords = ["决战", "打戏", "对决", "激战", "交锋", "对峙", "战斗", "对打", "搏斗", "厮杀", "刀剑"]
is_combat = any(keyword in scene_lower for keyword in combat_keywords)

# 根据环境返回对应的打戏环境
if is_combat:
    if env in ["forest", "garden"]:
        return "forest_combat"
    elif env == "rain":
        return "rain_combat"
    elif env == "night":
        return "night_combat"
    else:
        return "urban_combat"
```

**验证结果**：
- ✅ 竹林决战 → forest_combat
- ✅ 街头对战 → urban_combat
- ✅ 雨中激战 → rain_combat
