## ⚠️ 注意事项

1. **模板库影响**：如果场景已存在于模板库中，系统会优先使用模板库中的内容。为了测试 `mild_mode` 功能，需要设置 `use_template=False`。

2. **向后兼容性**：`mild_mode=False` 是默认值，确保现有代码不受影响。

3. **场景识别**：`mild_mode` 只对识别为打戏场景（emotion="combat"）的场景生效，对其他场景类型没有影响。
