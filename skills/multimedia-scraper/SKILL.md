# 多媒体抓取工具

一键抓取抖音、小红书、微信视频号的热门内容。

## 使用方法

### 1. 检测 Python 环境

```bash
python --version
```

- 未安装 → 引导安装 Python 3.8+
- 已安装 → 继续

### 2. 执行抓取

```bash
cd scripts && python scrape.py -k "关键词"
```

脚本会自动安装依赖（requests）。

## 命令行参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `-k, --keyword` | 搜索关键词（必填） | `-k "AI工具"` |
| `--json` | 输出原始 JSON | `--json` |

## 支持平台

| 平台 | 图标 |
|------|------|
| 抖音 | 🎵 |
| 小红书 | 🔴 |
| 微信视频号 | 📱 |
