## 内容索引

### 上下文溢出解决方案 (2026-02-02)

**问题**：
- 错误信息："Context overflow: prompt too large for the model"
- 原因：对话历史过长，超过模型上下文限制
- 限制：zai/glm-4.7 最大 131k tokens

**解决方案**：

#### 1. 定期清理
- 发送 HEARTBEAT_OK 清理不必要的历史
- 定期检查对话长度

#### 2. 使用子代理
- 复杂任务用 sessions_spawn 启动独立会话
- 子代理独立运行，不占用主会话上下文
- 适合：长时间任务、大量数据处理

#### 3. 任务分解
- 大任务拆分成多个步骤
- 每次只关注当前步骤
- 避免一次性处理过多内容

#### 4. 文件记录
- 中间结果写入文件
- 减少对话中的重复内容
- 需要时从文件读取

#### 5. 简洁回复
- 保持回复简洁
- 避免冗长描述
- 必要时使用 NO_REPLY

### 记忆管理优化

#### 定期归档
- 旧的 daily memory (超过 30 天) 归档到 memory/archive/
- 只保留最近 30 天的 daily memory

#### 提炼长期记忆
- 重要信息提炼到 MEMORY.md
- 删除 daily memory 中的重复内容
- 保持 MEMORY.md 精简

#### 分类索引
- 使用清晰的标题和结构
- 避免重复记录
- 定期删除过时信息

### 使用场景

**何时使用子代理**：
- 长时间运行的任务
- 大量数据处理
- 需要隔离的工作流
- 可能产生大量输出的任务

**何时直接回复**：
- 简单问答
- 短任务
- 快速反馈
- 不需要持久化的工作
