# Memory: Projects - 项目记忆

存储所有项目相关的详细信息，包括商业计划、技术方案、进度等。

## 使用方法

通过 Memory-Manager Skill 调用：

### 获取 AI 提示词商业计划
\`\`\`
memory_get("projects", "ai-prompts")
\`\`\`

### 搜索项目相关内容
\`\`\`
memory_search("AI 提示词评分系统")
\`\`\`
