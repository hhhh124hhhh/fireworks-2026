# RSS Grabber v2.0 - 中英文显示说明

> 版本：v2.0  
> 更新时间：2026-03-18 08:16

---

## ✅ 功能说明

### 中英文显示方式

**标题和原文内容都同时保存中英文:**

| 字段 | 内容 | 说明 |
|------|------|------|
| **标题** | 中文翻译 (或英文原文) | 主要显示字段 |
| **标题 (英文)** | 英文原标题 | 单独字段保存 |
| **原文内容** | 中文翻译 (或英文原文) | 主要显示字段 |
| **原文内容 (英文)** | 英文原内容 | 单独字段保存 |
| **是否翻译** | 是/否 | 标记是否经过翻译 |

---

## 📊 数据示例

### JSON 格式

```json
{
  "record_id": "46a205a7067ce3e5",
  "source": "openai",
  "title": "Introducing GPT-5.4 mini and nano",
  "title_en": "Introducing GPT-5.4 mini and nano",
  "content": "GPT-5.4 mini and nano are smaller, faster versions...",
  "content_en": "GPT-5.4 mini and nano are smaller, faster versions...",
  "is_translated": true
}
```

## 🔧 当前状态

**注意:** 当前版本保留了英文原文，但尚未集成真实翻译 API。

**下一步:** 集成翻译 API 后，`标题` 和 `原文内容` 字段将显示中文翻译，`标题 (英文)` 和 `原文内容 (英文)` 保留原文。

---

## 📋 字段说明

### 必填字段

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 采集轮次 | 文本 | ✅ | 唯一记录 ID |
| 采集时间 | 日期时间 | ✅ | 抓取时间 |
| 搜索关键词 | 文本 | ✅ | RSS:源名称 |
| 信息源 | 文本 | ✅ | openai/techcrunch 等 |
| 标题 | 文本 | ✅ | 中文或英文 |
| 原文内容 | 文本 | ✅ | 中文或英文 |
| 原文链接 | 超链接 | ✅ | 文章 URL |
| 是否翻译 | 单选 | ✅ | 是/否 |

### 可选字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 标题 (英文) | 文本 | 英文原标题 |
| 原文内容 (英文) | 文本 | 英文原内容 |
| 发布时间 | 日期时间 | 文章发布时间 |
| 作者 | 文本 | 作者姓名 |
