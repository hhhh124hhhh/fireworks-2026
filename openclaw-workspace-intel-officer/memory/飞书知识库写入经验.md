## 🎯 核心结论

**写入飞书知识库的正确方法:**
使用 `feishu_create_doc` 工具 + `wiki_space` 参数，**直接创建文档到知识库空间**

## ✅ 正确方法

### 工具调用

```
工具：feishu_create_doc
必需参数:
- title: 文档标题
- markdown: 文档内容（Markdown 格式）
- wiki_space: 知识库空间 ID

示例:
{
  "title": "📊 2026-03-13 深度情报日报",
  "markdown": "# 完整的情报内容...",
  "wiki_space": "7616670088766393307"
}
```

### 返回值

```json
{
  "doc_id": "RCeqdsZxnou4voxfSslcXcTBnWg",
  "doc_url": "https://www.feishu.cn/wiki/NEBfwwS9yi2Cedk3AZWcsOxqnPb",
  "log_id": "20260313181104...",
  "message": "文档创建成功"
}
```

**注意:** 返回的 `doc_url` 是飞书知识库链接（`/wiki/` 开头）

---

## ❌ 错误方法（不要使用）

### 错误 1: 先创建文档再添加到空间

```
❌ 错误流程:
1. feishu_create_doc（不传 wiki_space）→ 创建普通文档
2. feishu_wiki_space_node create → 尝试添加到知识库
3. 结果：field validation failed / not found
```

**原因:** 飞书知识库节点 API 有特殊的字段验证要求，普通文档无法直接转换为知识库节点

---

### 错误 2: 使用错误的 obj_type

```
❌ 错误参数:
{
  "obj_type": "doc",  // 应该是 "docx"
  "node_type": "origin"
}
```

**正确:** `obj_type` 必须是 `"docx"`

---

### 错误 3: 缺少必需参数

```
❌ 错误:
{
  "title": "文档标题"
  // 缺少 markdown 或 wiki_space
}
```

**必需参数:** `title` + `markdown` + `wiki_space`

## 🔑 关键知识点

### 1. 知识库空间 vs 普通文档

| 类型 | 创建方式 | URL 格式 | 用途 |
|------|---------|---------|------|
| **知识库文档** | feishu_create_doc + wiki_space | `/wiki/` 开头 | 知识库内容沉淀 |
| **普通文档** | feishu_create_doc（无 wiki_space） | `/docx/` 开头 | 临时文档 |

### 2. wiki_space 参数的作用

```
wiki_space 参数告诉飞书:
- 将文档创建到指定的知识库空间
- 自动创建知识库节点
- 返回知识库 URL（/wiki/开头）
```

### 3. 文档类型

```
飞书文档类型:
- docx: 新版飞书文档（推荐）
- doc: 旧版飞书文档（不推荐）

知识库节点类型:
- origin: 原创节点
- shortcut: 快捷方式（关联已有文档）
```

## 🛠️ 常见问题解决

### 问题 1: field validation failed

**原因:** 使用了错误的参数组合

**解决:**
```
❌ 错误:
feishu_wiki_space_node create + obj_type: docx

✅ 正确:
feishu_create_doc + wiki_space: "空间 ID"
```

---

### 问题 2: not found

**原因:** 空间 ID 错误或权限不足

**解决:**
1. 确认空间 ID 正确（从飞书 URL 获取）
2. 确认已获得知识库写入权限
3. 使用 feishu_wiki_space get 验证空间存在

---

### 问题 3: 文档创建成功但不在知识库中

**原因:** 没有传 `wiki_space` 参数

**解决:**
```
❌ 错误:
feishu_create_doc { title, markdown }

✅ 正确:
feishu_create_doc { title, markdown, wiki_space }
```

## 🎯 经验教训总结

### 教训 1: 不要尝试复杂的多步操作

```
❌ 错误思路:
1. 创建普通文档
2. 获取文档 ID
3. 添加到知识库空间

✅ 正确思路:
一步到位：feishu_create_doc + wiki_space
```

### 教训 2: 优先使用高级 API

```
feishu_create_doc + wiki_space 是高级 API
- 自动处理知识库节点创建
- 自动设置正确的字段格式
- 返回知识库 URL

feishu_wiki_space_node 是低级 API
- 需要手动处理字段验证
- 容易出错
- 仅用于特殊场景
```

### 教训 3: 验证是关键

```
每次写入后都要验证:
1. 使用 feishu_wiki_space_node list 查看节点
2. 确认文档标题正确
3. 确认 URL 格式是 /wiki/ 开头
```
