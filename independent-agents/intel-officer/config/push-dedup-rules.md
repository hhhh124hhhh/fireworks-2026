# 🚫 推送去重规则（重要）

**生效时间:** 2026-03-16 14:15  
**适用范围:** 所有情报推送任务（晨间/晚间/夜间）

---

## 🎯 核心原则

**一个热点最多推送 2 次，除非有重大反转**

---

## 📋 去重检查清单

### 推送前必须检查

```
[ ] 这个热点晨间/午间推过吗？
[ ] 今天有新增进展吗？
[ ] 这是第几次推送同一个热点？
[ ] 新增信息值得再推一次吗？
```

### 跳过规则

**必须跳过的情况：**
1. ❌ 同一个热点已推送 2 次
2. ❌ 没有新增进展/反转
3. ❌ 只是热度上升，没有实质变化
4. ❌ 纯资讯类内容（无创作价值）

**可以推送的情况：**
1. ✅ 有重大反转（如事件反转、新证据）
2. ✅ 有新增进展（如官方回应、处罚结果）
3. ✅ 有深度分析角度（如产业链深挖）
4. ✅ 第一次推送的新热点

## 🛠️ 推送优化策略

### 晨间推送（09:30）
**内容:** 昨夜今晨热点 + 全天热点预测  
**重点:** 发现新热点，判断热点潜力  
**数量:** 最多 3 个热点

### 晚间推送（20:30）
**内容:** 相对晨间的新增/反转/确认  
**重点:** **只推送新增变化**，不重复晨间内容  
**数量:** 最多 3 个新增热点  
**规则:** 
- 晨间推过的热点，晚间必须有新增才能再推
- 同一个热点全天最多推送 2 次

### 夜间推送（05:00）
**内容:** 全日汇总 + 深度分析  
**重点:** 深度分析，不重复推送  
**数量:** 1 份汇总报告  
**规则:** 不推送，只存档

## 📈 效果评估

### 优化前
- 每日推送：5-7 次
- 重复率：~60%
- 用户感知："总是推送相同内容"

### 优化后
- 每日推送：2-3 次
- 重复率：<20%
- 用户感知："每次都有新信息"
