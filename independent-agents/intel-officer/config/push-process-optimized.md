## ✅ 优化方案

### 1. 推送时间规则（精简版）⭐

**固定推送（每天 3 次）：**
```
08:30 晨报 → 推送 08:00-08:30 数据（晨间轮）
12:30 午报 → 推送 12:00-12:30 数据（午间轮）
21:00 日报 → 推送 08:00-21:00 数据（全平台聚合）
```

**取消推送：**
```
❌ 09:30 晨间双层情报（与晨报重复）
❌ 临时简报（除非重大突发事件）
❌ 夜间轮推送（合并到日报）
```

**检查清单:**
- [ ] 确认数据时间戳是最新的
- [ ] 确认与上次推送间隔>3 小时
- [ ] 确认推送内容有独特价值
- [ ] 确认数据来源（晨间轮/午间轮/晚间轮）
- [ ] 确认推送内容匹配时间段

---

### 2. 推送方式（多通道）

**优先级：**
1. **飞书消息** (最可靠)
   - 接收方：郝工 (ou_c1f49efdd595b46e212560e66abc7205)
   - 接收方：bot2 (需要确认 open_id)

2. **sessions_send** (备选)
   - 需要正确的 sessionKey
   - 失败后自动降级到飞书消息

3. **飞书知识库更新** (必须)
   - 更新 Intel Officer 深度情报库
   - 所有接收方可查看

### 3. 重试机制

```
第 1 次：立即推送
第 2 次：5 分钟后重试（如果失败）
第 3 次：30 分钟后重试（如果失败）
记录：写入推送日志
```

**推送日志格式:**
